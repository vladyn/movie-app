## 5. Key Decisions and Rationale

- The existing workspace was being changed from a movie mockup to rabbit profiles when the first request arrived. The infinite scroller was applied to the rabbit screen. The user then asked specifically for rabbit picture sizing and a three-rabbit initial list, confirming that direction.
- The first rabbit is randomly selected, then all three appear once in sequence. Later batches cycle through the same three local profiles because there is no API or larger data set.
- `onScrollBeginDrag` arms `onEndReached` so mount-time or repeated end notifications do not add batches on their own.
- Picture size is computed from `useWindowDimensions`: `floor(max(0, min(width - 48, height * 0.4, 360)))`. This fits the list's 24 px horizontal padding on each side and limits height on portrait devices.
